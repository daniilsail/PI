# Аналитическая система рекомендаций для спортивной парусной яхты SB20

Аналитическая система предназначена для того, чтобы спортсмены могли быстро вносить данные о своих тренировках и соревнованиях, а затем совместно с тренерами получать аналитику на основе этих данных и рекомендации по оптимизации настроек лодки.

**Польза системы:**
Спортсмен может видеть свои исторические данные и рекомендации в наглядном виде, тренер может следить за прогрессом своих спортсменов, совместно они смогут быстрее получать результаты и адаптироваться к изменениям.

**Функциональные требования:**
1.	Спортсмен должен иметь возможность зарегистрироваться в системе.
2.	Спортсмен должен иметь возможность внести данные о своем выходе на воду: дата, время, внешние условия, настройки яхты.
3.	Спортсмен должен иметь возможность загрузить данные с носимых на борту устройств в одном из форматов: CSV, VTK, VKX.
4.	Спортсмен должен иметь возможность привязать данные с носимых на борту приборов к тренировке.
5.	Спортсмен должен иметь возможность скорректировать данные о тренировке.
6.	Система должна исключать недостоверные данные из расчетов при формировании отчета и рекомендаций
7.	Система должна анализировать проведенную тренировку после загрузки всех данных о ней, вычислять основные метрики и сохранять их.
8.	Система должна показывать краткий отчет по тренировке после внесения данных о ней.
9.	Спортсмен должен иметь возможность получить подробный отчет о тренировке по запросу.
10.	Тренер должен иметь возможность просматривать исторические данные спортсменов и формировать отчет с рекомендациями по каждому спортсмену.
11.	Тренер должен иметь возможность вносить свои заметки о тренировке спортсмена.
12.	Спортсмен должен иметь возможность внести данные о внешних условиях и получить рекомендации по настройкам, подходящим под эти условия, на основе исторических данных.
13.	Тренер и спортсмен должны иметь возможность выгрузить отчет о тренировке и рекомендации к ней в формате pdf.
14.	Система должна автоматически улучшать точность рекомендаций по настройкам по мере накопления новых данных.
15.	Спортсмен и тренер должны иметь возможность оценить качество полученного отчета и рекомендаций.
